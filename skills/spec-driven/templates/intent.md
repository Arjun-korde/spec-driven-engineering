## Gate checklist
- [ ] Clear problem statement
- [ ] Primary and secondary users defined
- [ ] Vision separated from implementation
- [ ] Capabilities, out of scope, constraints, risks listed
- [ ] Success criteria defined
- [ ] Ambiguity test passed (two developers would build the same thing)
- [ ] Problem stated without assuming a technical solution
- [ ] Desired outcome can be measured or observed
- [ ] Out of scope written before implementation begins
- [ ] Open questions captured, each with an owner
